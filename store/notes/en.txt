Cloud first is now the default engine mode. Blind judges rated the on-device engine below Google on every language it served, so readers still on the old default, on-device first, move to cloud first once. On-device only is never changed, and picking on-device first again keeps it. With cloud first, chat text that the on-device model used to translate now goes to the translation engine you picked.

Cloud first now does what its name says: when the cloud fails, a ready on-device model takes the line instead of showing an error. When the engine hands a line back untranslated, it is asked once more with the channel's language as the source. Lines no table recognises are checked against the browser's own language detector.

Fixes: three rules no longer name the wrong language ("niye" in Turkish, "dat" in Romanian, "miks" in Finnish). Translations through MyMemory no longer show stray brackets around protected names. The About tab now opens Twitch Chat Translator on your browser's store.
