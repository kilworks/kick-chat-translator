# 2026-11-19, UI comfort pass, phase 0 and 1

Branch `feat/ui-comfort` from `ea7c4f3` (3.5.0).

## Measured

- Snapshots: the Display tab threw on `translatedLineHeight.toFixed` (stub
  settings missing newer keys) and dropped the page past its first card;
  Filters rendered no section; `debug` matched no tab. Fixed by building the
  stub from `defaultSettings()` and asserting section counts per tab
  (providers 4, display 3, filters 4, advanced 4, activity 2, about 3).
  Activity counts 2 in the stub, 1 on a fresh real profile (stats served).
- Engine dispatch, 6 pairs of `engineMode` x `localEnabled`: 4 distinct
  behaviours; `local-only` + off translated nothing; `local-first` + off and
  `cloud-first` + off are both cloud only. Pinned in
  `engineMode.combos.test.ts` (27 cases).
- Popup height: 649 to 681px at first run on 3.5.0 (10 languages). After the
  gate moved to all 43 languages: 11 pairs over 600 that the old gate never
  measured, Tamil 760px (stats question beside two stacked buttons, 12 lines).
  End of pass: 43 x 6 fit, tallest 600px.
- DeepL free figure: support search gives 500,000 a month for API Free; the
  same support site says API Free can no longer be bought (Developer plan,
  1,000,000 characters, no reset). The official page itself answered 403 to
  the fetch, so no figure is quoted in the UI now.

## What did not work

- `break-words` on the stats labels to stop a Greek wrap: it split Tamil
  words instead and took Tamil from 576 to 616px. Content-sized columns
  fixed Greek without touching Tamil.
- The critique's 16px above "Display" pushed Spanish to 604px; recovered by
  dropping a redundant 4px pad on the switch row.
- A key-removal script that matched the key line only left the value of
  two-line entries behind, in 7 catalogues (cs, pl, sk, sv, yue, zh, zh-tw):
  caught by tsc, fixed, script now drops the value line too.
- A translation run was cut by a session end with 0 of 42 languages written;
  resumed whole.

## Probes that were wrong

- The popup gate stub returned providers as `{ ok: true }` where the type is
  `available`: every engine showed as down in the 3.5.0 captures.
- The gate claimed "every interface language" over 10 of 43.
- Kit gates on snapshot pages: `verify_keyboard` reports dead tab arrows
  because the snapshot strips scripts, and an unreachable glossary that a Tab
  walk reaches. Both stub artefacts.
