# Security policy

## Supported versions

Only the latest version published on the Chrome Web Store and addons.mozilla.org gets fixes. Both stores update installs on their own.

## Reporting a vulnerability

Please report it privately through GitHub: [open a security advisory](https://github.com/kilworks/kick-chat-translator/security/advisories/new). Don't open a public issue for it.

You'll get a first answer within 7 days. Once a fix ships, the advisory is published with credit to you, unless you'd rather stay anonymous.
